# MujMart Backend

This directory will contain the Node.js/Express server for MujMart.

## 🚀 Backend Roadmap
Information for the Backend Developer (Student 2) is located in the **[Root README.md](file:///Users/souvik/Project/MujMart/README.md#🚀-backend-development-roadmap-student-2)**.

## Getting Started
1.  Initialize the project: `npm init -y`
2.  Install dependencies (see root README for the list).
3.  Set up your `.env` by copying `.env.example`.
4.  Run development server: `npm run dev` (once scripts are added to `package.json`).
